# 全体マップ画面 UIデザイン

## 背景

高速道路の事故・交通情報アプリを作るにあたり、まず「現在地・上り下り・路線番号（Eナンバー）を入力すると、その路線の交通情報がわかる」というアプリの中核画面のひとつである**全体マップ画面**（起動時に最初に見る画面）のUIを設計した。

参考として調査した [c-ihighway.jp](https://www.c-ihighway.jp/pcsite/map?area=area03)（NEXCO中日本 iHighway）は、実際の地形に沿った地図の上に地名がすべて表示されており、路線もすべて同じ色で描画されているため、どこがどの路線か・どちらが上りかが分かりにくい。この課題を解決するデザインを作る。

## スコープ

- 対象画面：**全体マップ画面**（エリア単位で複数路線を俯瞰する画面）のみ
- 路線ごとの詳細ビュー（IC順一覧など）、事故・通行止め等の情報オーバーレイは**別セッションで設計する**（データソース未確定のため今回は含めない）
- エリア切り替え（北海道／東北／北陸信越／関東／東海／関西／中国／四国／九州沖縄）の仕組みは現行サイトのパターンを踏襲する

## 見た目のスタイル：模式図（路線図）

実際の地形に沿わせず、鉄道の路線図のようにデフォルメした模式図で表現する。位置関係の正確さより、路線のつながり・色分け・番号の分かりやすさを優先する。

- 路線ごとに固有の色を割り当てる
- 路線の脇にEナンバーのバッジ（色付きピル、例：`E18`）を配置する
- 同じ道路を複数のEナンバーが共有する区間は、線は1本のまま、バッジを複数並べて表示する（例：`E1` `C1`）

## 地点・ラベルの表示ルール

情報量を絞り、初期状態はスッキリ見せることを最優先する。

| 種別 | 初期状態 | インタラクション |
|---|---|---|
| JCT（分岐・合流点） | 常に地名ラベルを表示 | ― |
| 路線の端点（画面外へ続く場所） | 常に地名ラベルを表示 | ― |
| IC | 無地の点のみ | タップで吹き出し表示（地名＋路線名） |
| SA/PA | 無地の点のみ（ICよりさらに控えめな見た目） | タップで吹き出し表示（地名＋路線名） |

スマートフォン利用を主想定とするため、ホバーではなく**タップ**を基本の操作とする。

## 上り／下り表示

日本の高速道路は「上り＝より栄えた方面へ向かう方向」「下り＝その逆」であり、この向きは路線ごとに異なる（例：北陸道の上りは米原方面、上信越道の上りは東京方面）。

- 各路線の端点ラベルのそばに、小さい矢印アイコン＋「上り」「下り」の2文字だけを常時表示する
- 行き先の都市名までは出さない（最小限にとどめ、常時表示でも画面を賑やかにしない）
- 上り／下りの向きは路線データ側で「どちらの端点が上りか」を保持する設計とする

## インタラクション

- 色付きの路線ライン、または右側の路線リスト（凡例）をタップ → その路線だけハイライト（濃く表示）、他の路線は薄く表示する。画面遷移はしない
- 「すべて表示に戻す」操作でハイライトを解除する

## UIコンポーネントライブラリ：shadcn/ui

実装（React/Next.js）では **shadcn/ui**（Radix UI + Tailwind CSSベース）またはそれに近い構成を採用する。今回のプロトタイプでは、Artifact環境がCDN/npmを読み込めない制約上、shadcn/uiのデフォルト（zinc）テーマと同じデザイントークン（背景色・境界線・角丸0.5rem・シャドウ）を手書きCSSで再現した。実装時は実際の shadcn/ui コンポーネントに置き換える。

用いたコンポーネントの対応：

| プロトタイプでの要素 | 対応する shadcn/ui コンポーネント |
|---|---|
| エリア選択 | `Select` |
| 地図カード／凡例パネル | `Card` |
| 路線バッジ（E8, E18など） | `Badge`（カスタムカラー） |
| IC/SA・PAタップ時の吹き出し | `Popover` |
| 凡例の路線リスト項目 | `Button variant="outline"` |

## コンポーネント構成（実装イメージ）

- `MapCanvas` — 全体描画（模式図のSVG／Canvas）
- `RouteLine` — 路線1本を表す。色・Eナンバーバッジ・ハイライト状態を持つ
- `NodeMarker` — JCT／IC／SA・PA／端点の種別ごとに見た目が変わるノード
- `DirectionTag` — 端点そばの「上り／下り」表示
- `NodeTooltip` — IC/SA・PAタップ時の吹き出し（shadcn `Popover`）
- `AreaSelector` — エリア切り替え（shadcn `Select`）

## データ構造（概念レベル）

```
Route {
  id
  eNumbers: string[]       // 複数Eナンバー対応
  name                     // 例：上信越道
  color
  ascendingEndpointId       // 上り側の端点ノードID
  descendingEndpointId      // 下り側の端点ノードID
  ascendingLabel             // 上り方面の代表都市名（内部データ用、UIには出さない）
  descendingLabel
  path: nodeId[]             // 模式図上のノード列
}

Node {
  id
  name
  type: "JCT" | "IC" | "SA" | "PA" | "endpoint"
  x, y                      // 模式図上の座標（実座標ではない）
  connectedRouteIds: string[]
}
```
